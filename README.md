# 本地换钥工作台

一套本地分析表的部分列加密演示：真实 AES-256-GCM 加解密、密钥版本清单、原地逐块轮换、读写协调、以及可操作的网页工作台。全部数据为虚构，密钥为本地测试钥，**不连接任何真实密钥服务**。

- 运行环境：Node.js ≥ 22.5（使用内置 `node:sqlite` 与 `node:crypto`），零第三方依赖。
- 仅监听 `127.0.0.1`。

## 快速开始

```bash
node src/cli.js init --data-dir ./data --rows 240   # 生成密钥与虚构数据，并预置一次半程轮换
node src/cli.js serve --data-dir ./data --port 4173 # 打开 http://127.0.0.1:4173
```

`init` 会：

1. 为 `pii / analytics / audit` 各生成一把活动钥；
2. 写入若干虚构事件（邮箱、会话标签、审计引用三列分别加密）；
3. 为 `pii` 与 `analytics` 生成第二代钥并切换写入；
4. 把 `pii` 列迁移一半后暂停——打开页面即可看到**两代密文并存**。

数据目录下的 `workbench.sqlite`（含 WAL）与 `keyring/*.key`（0600）都已在 `.gitignore` 中排除。

## 页面能做什么

| 区域 | 操作 |
| --- | --- |
| 总览 | 行数、两代并存列数、活动租约、缓存统计、各用途状态 |
| 密钥清单 | 每把钥的状态、指纹、**销毁条件未满足的具体原因**；启用/销毁 |
| 轮换 | 选用途与块大小 → 开始/继续；单块推进、跑到结束、暂停、恢复、回滚、删备份、放弃任务；实时进度与派生分布 |
| 读取一格 | 指定行与列读取，显示来源（DB/缓存）与所用钥 id；可关闭缓存 |
| 写入与改写 | 追加虚构记录；把某格改写为活动钥加密 |
| 数据浏览 | 每格显示明文与信封中的钥 id，两代一目了然 |
| 储留钥与在途读取 | 手动占用旧钥租约，验证"旧查询未结束时销毁被拒" |
| 用途撤销与缓存 | 撤销/恢复用途、清缓存，观察撤销后读与写被拒 |
| 版本清单 | 只含元数据与指纹的 JSON |

## 核心顺序（原地逐块）

1. **先启用新钥**：写路径立刻改用新钥，`promote` 把旧钥置为 `retiring`。
2. **再回填**：从 `id` 游标分块重加密旧行，每块一个 `BEGIN IMMEDIATE` 事务，备份镜像与游标同事务提交。备份表只保存 `id` + 被迁移的那一列，不复制整行。
3. **校验**：逐行确认钥 id 与 GCM 认证；有任何旧钥行即失败。
4. **删备份**：仅在确认活跃表已无旧钥密文后允许。
5. **销毁旧钥**：全部退出条件在同一事务内复核（活跃表、备份、影子表、租约、静默期、未终结任务）。

为什么先切写再回填：这样并发写入永远落在目标钥下，回填只需处理历史行，游标之后不会出现旧钥"漏网"行。

## 并发与恢复语义

- **读**：先取短期查询租约再解密，读完释放；命中内存缓存时不取租约，但仍校验用途是否撤销、钥是否已销毁。
- **写**：每次写入读取当前活动钥；用途撤销后拒绝写入。
- **中断**：每块事务提交后才推进游标，进程被 `kill -9` 最多丢一个未提交块。重启后，若属主进程已死（同机 PID 检查 + 心跳超时），任务被标记 `interrupted`，可从游标继续或从备份回滚。
- **回滚**：逐行比对本次任务写入的密文指纹；若该行已被并发改写，记为冲突并**保留现值**，不覆盖。
- **销毁**：在 `BEGIN IMMEDIATE` 中复核条件并翻转状态，租约获取也在 `BEGIN IMMEDIATE` 中完成，两者无法交错；不存在强制销毁入口。

## CLI

```bash
node src/cli.js status  --data-dir ./data          # 全量状态 JSON
node src/cli.js keys    --data-dir ./data          # 每把钥 + 销毁条件
node src/cli.js rekey   --data-dir ./data --purpose pii --chunk-size 50
node src/cli.js destroy --data-dir ./data --key-id 0000000000000001
node src/cli.js verify  --data-dir ./data          # 对进行中的任务推进一步校验
```

## 测试

```bash
node --test
```

覆盖：AES-GCM 往返/AAD 绑定/篡改拒绝/跨用途拒绝；轮换迁移与校验；分块失败整块回滚；回滚不覆盖并发写；备份/租约阻止销毁（且一个用途的备份不会钉住另一个用途的旧钥）；撤销清缓存；HTTP 错误不泄漏堆栈与输入、静态目录逃逸防护、明文不落盘；UI 控制器在真实 API 上跑通；以及**子进程跑到一半 SIGKILL 后从游标恢复**。

## 取舍与边界

- 只实现原地逐块；影子副本的对照与选择规则见 [docs/strategy.md](docs/strategy.md)。
- 本地测试钥以文件存放，演示用；生产应使用 KMS/HSM，并保留同样的"最后销毁、条件原子复核"原则。
- 明文缓存仅在进程内存，不落库、不写临时文件。
